# 🎨 AI Image Generator Web App

A clean, responsive single-page Web Application built with HTML, CSS, and JavaScript that generates high-quality images based on user text prompts.

---

## ✨ Features
- 🚀 **Instant AI Generation:** Renders images from text inputs.
- 📱 **Responsive Design:** Works smoothly on desktop and mobile screens.
- ⚡ **Lightweight:** Built with zero heavy dependencies.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** Open AI Image API
